# Security Policy

## Supported Versions

This project is in bootstrap phase. The `main` branch is the supported version.

| Version | Supported |
|---|---|
| main branch | Yes |
| older tags | No |

## Reporting a Vulnerability

If you discover a security vulnerability in this project — including misconfigured pipeline steps that could lead to supply chain attacks, insecure default configurations, or vulnerabilities in the validator scripts — please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

### How to Report

1. Email **hiagokinlevi@protonmail.com**.
2. Or open a [GitHub Security Advisory](https://github.com/hiagokinlevi/secure-pipeline-blueprints/security/advisories/new) via the repository's Security tab.

### What to Include

- A clear description of the vulnerability
- Which blueprint file(s) are affected
- Potential impact (e.g., CI/CD supply chain attack vector, secret exposure)
- Suggested remediation if known

### Response Timeline

- **Acknowledgment**: within 48 hours
- **Initial assessment**: within 5 business days
- **Resolution**: within 30 days for critical/high severity issues

### Supply Chain Security Note

All tool references in blueprints are pinned to specific versions or SHA digests where possible. If you find a reference that is unpinned (which could be a supply chain risk), please report it as a vulnerability.

Thank you for helping keep this project and the community secure.
